# Body-Ordered Bond-Order Potential (BOBOP) for Robust Extrapolation of Potential Energy Surfaces

## Description
PyTorch implementation of Body-Ordered Bond-Order Potential

## Requirement
- Python 3.10 or later
- Numpy
- Ase (Atomic Simulation Environment)
- PyTorch
- PyTorch Geometric

## Installation
Please refer to the ```setup.py``` for installation instructions.
